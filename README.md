# Online Menu

C# və Windows Forms istifadə edilərək hazırlanmış sadə restoran onlayn menyu tətbiqi.

## Xüsusiyyətlər

- Restoran menyusuna baxış
- Sadə və istifadəsi rahat interfeys
- Menyu bölmələrinin təşkili
- Rahat naviqasiya
- Windows Forms əsaslı tətbiq

## İstifadə olunan texnologiyalar

- C#
- .NET
- Windows Forms
- Visual Studio

## Haqqında

Bu layihə C# və Windows Forms texnologiyalarından istifadə bacarıqlarını inkişaf etdirmək və restoran menyusu üçün sadə masaüstü tətbiq hazırlamaq məqsədilə yaradılmışdır.
